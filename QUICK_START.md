# Quick Start

## Prerequisites
- Node.js 20+
- npm

## Install & Run
```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Main User Flow
1. Add task (`/tasks/new`)
2. AI analysis runs automatically on save
3. Enter fatigue on home (`/`)
4. Check recommendation order (`/analysis`)
5. Complete task and review weekly record (`/weekly-record`)
